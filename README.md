# PT-Mail-Tracking-Gemini

Ein leichtgewichtinales Web-Tool zur Erfassung, Verwaltung und Auswertung von E-Mail-Aufkommen nach Abteilungen (Vertrieb, Einkauf, Rechnungen) im Stundentakt.

## Funktionen
- **Datenerfassung:** Schnelle Eingabe pro Wochentag, Stunde und Abteilung mit automatischer Tagessummen-Berechnung.
- **Diagramme & KPIs:** Visualisierung der Daten via Chart.js mit Filteroptionen nach Jahr und Kalenderwoche.
- **Datensicherung:** Lokale Speicherung im Browser sowie Export/Import-Funktion über JSON-Dateien mit Zeitstempel.
- **Theme:** Unterstützung für Light- und Dark-Mode.

## Nutzung
Die Anwendung läuft direkt im Browser über GitHub Pages.
